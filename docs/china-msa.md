# 中国海事局の航行警告

中国海事局本局の公開「航行安全 → 安全信息 → 航行警告」の16地域を確認する。
Pythonによる通常のHTTPS取得を使用し、VPN・認証回避・非公開APIは使用しない。

既存30分ワークフローから呼び出し、state/china_msa.jsonで毎時に制限する。
1回最大120リクエスト、開始から8分で新規リクエストを停止、間隔1.5秒以上。
403/429では残りのアクセスを中止し、前回取得した本文を保持する。
本文は24時間キャッシュし、初回は各地域最新最大60記事、以後は新着と保存分を確認する。
未確認・確認の古い地域から処理する。予算で未完了の場合もエラーとして記録する。

中国語の軍事任務・演習・射撃・ロケット等を対象にする。英訳との二重描画を避ける。
本文の各点の結線は独立した多角形、中心・半径は円として扱う。
北京時間（UTC+8）をUTCに換算し、取消・期限切れを除外する。
時刻のない日付範囲は開始日00時〜終了日の翌日00時を範囲とし、時刻未記載と明示する。
取得間隔内の再解析は保存済み本文だけを使用し、ソースへの通信や最終取得時刻の更新は行わない。
発表履歴は有効警報の一覧ではないため、有効期間が解析できない記事は未描画欄に保留する。
国コードCNは発行国であり、海域の領有・演習実施国を意味しない。

全国16地域を対象にするが、有効警報全件の網羅を保証するものではない。
地域別の取得成否はweb/maritime/china_msa.jsonのmetadata.regionsと、暗号化された確認用ページに記録する。
継続運転の成否は、複数回のActions実行で確認する。
