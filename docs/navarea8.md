# インドNHO NAVAREA VIII

公式入口: https://hydrobharat.gov.in/navarea-warnings/

毎時、公式ページの表示用ダウンロードリンクを通常のChromiumで確認し、同じ公式ドメインの現行PDFを1回ダウンロードする。
静的HTMLに残る2025年のPDFリンクは使用しない。認証情報の抽出・転用、非公開APIの直接利用、VPN、認証回避、アクセス拒否時の再試行はしない。
閲覧端末は公開済みJSONを読むだけで、インド側へのアクセスを起動しない。

PDFの「WARNINGS IN FORCE AS ON」の日付を検証し、3日を超える古い一覧は取得成功として扱わない。
全メッセージを分離してから取消を反映し、軍事・射撃・ミサイル・安全保障等の該当分を抽出する。
本文に明記されたUTCの取消時刻を過ぎた警報を除外する。詳細な日別実施時刻が未解析の場合は未確定と表示する。
元の発行日時・本文は保持し、取得時刻と区別する。

明記された座標列・緯度経度の上下限・複数区域・円を処理する。
単一の中心、半径、方位が明記された扇形は球面計算し、円弧を1度間隔の頂点で近似する（原文と計算上の注意を併記）。
複合した円弧など、境界を確定できない場合は参照座標に限定し、推測の危険区域は作らない。

country=INは発行調整機関の国。NAVAREA VIIIはインド領海だけではなく、周辺国の情報を含む。実施国・領有の判定とは区別する。

Python Playwrightは必要な回だけGitHubの標準Ubuntu実行環境にインストールする。無料の公開リポジトリ構成・既存の0ドル予算を変更しない。
取得失敗・PDFの鮮度不良は前回の成功分とエラー状態を公開する。確認用ページに他のソースと並べて表示する。
